# Ban System 1.21.11

**Commands**
<br>/punish [user] [reason] --> Bannt einen Spieler</br>
/unban [user] --> Entbannt einen Spieler
<br>/punishment add [name] [duration] --> Fügt einen neuen Bangrund hinzu</br>
/punishment remove [name] 
<br>/punishment list --> Zeigt alle vorhandenen Bangründe
